# Intelligent Automated Vending Machine System

## Project Demonstration

A complete project demonstration video is included in this repository.

## Overview

The Intelligent Automated Vending Machine System is an Arduino-based embedded systems project developed in Tinkercad.

The system allows users to select products, simulate digital payments, verify available balance, calculate change, dispense products using a servo motor, and provide visual feedback through an LCD display, LEDs, and buzzer notifications.

## Key Features

* Product Selection Interface
* Digital Payment Simulation
* Automated Product Dispensing
* Balance Return Calculation
* LCD-Based User Interface
* Green LED Success Indication
* Red LED Error Indication
* Buzzer Notifications
* Insufficient Balance Detection
* Automated System Workflow

## Components Used

* Arduino UNO
* 16x2 LCD Display
* 2 Potentiometers
* Servo Motor
* Slide Switch
* Green LED
* Red LED
* Piezo Buzzer
* Breadboard
* Jumper Wires

## System Workflow

1. User selects a product using the product selection potentiometer.
2. User inserts virtual money using the payment potentiometer.
3. The LCD displays product details and payment amount.
4. Purchase is confirmed using the slide switch.
5. The system verifies payment eligibility.
6. The servo motor dispenses the selected product.
7. Any remaining balance is calculated and displayed.
8. Error handling is triggered for insufficient balance conditions.
